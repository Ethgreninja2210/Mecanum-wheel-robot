# Mecanum-wheel-robot

I set out this project with not much idea where I was going but I knew I wanted to experiment with mechanum wheels and a robotic arm. I wanted this to be controlled by and ESP32 as I have not yet had a change to play with one of these and want to experiment further with the remote control and this seems like a wonderful chance to have these be like this. This set out the overall plan for the project which was for me to end with an RC car which has a small, light robotic arm and 4 mechanum wheels for funky movement.

## How To use/make

Start by printing the components from the STEP files (in the CAD folder) then test your electronics using the code (In the respective folder) and a breadboard to ensure all components are working (Wiring diagram bellow). After doing this, assemble the wheels and arm separately before placing the servos into the arm slots, these should be put asside for now.
To get started on the chassis, place the OLED into the case with the wires soldered BEFORE closing the case and then glue the back of the case into the slot on the main chassis. 
I then soldered up the motors and driver boards completely before sloting each motor into the respective arms, closing the arm lid and then glueing each bit into the chassis. 

Now go back to the arm and glue it into the chassis lid (there is an indent for it) and thread the servo wires through the slots before attaching them to the ESP along with the oled wires (If not already done) and screw the case shut with M3 Countersunk screws. 
Power the device, open the HTML file, and connect to the wifi (Password: 12345678)
